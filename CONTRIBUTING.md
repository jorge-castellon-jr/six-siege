# Contributing

This repo does not accept direct pushes to `main`. Fork it, make your changes on a branch, and open a pull request. Changes land only after the maintainer reviews and approves the PR.

## Workflow

1. Fork the repository.
2. Clone your fork and create a branch.
3. Make your changes and commit them on the branch.
4. Push the branch to your fork.
5. Open a pull request against `main` on [jorge-castellon-jr/six-siege](https://github.com/jorge-castellon-jr/six-siege).

Do not open a PR from a branch on this repository — you will not have write access. Use a fork.

## Review

PRs require an approving review from the code owner (`@jorge-castellon-jr`). Approvals reset if you push more commits after review, so the latest changes have to be re-approved.
